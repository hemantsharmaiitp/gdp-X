About the Project

The India GDP Prediction Dashboard is an interactive tool developed as part of our academic capstone project. It is designed to estimate future GDP based on user inputs like current GDP value, annual growth rate, and time horizon. The goal is to provide simple, accessible forecasting that helps visualize India’s economic trajectory.

How It Works

The tool uses a compound growth formula to calculate future GDP:

Future GDP = Current GDP × (1 + Growth Rate)Years

The backend is built using FastAPI, a modern Python framework that processes user input and returns predictions in real-time via a REST API.

Team Roles and Contributions

  • Model Developer: Created the core GDP forecasting algorithm using Python.
  • Backend Developer: Developed the FastAPI backend to handle user input and serve predictions.
  • Frontend Developer: Designed the user interface to interact with the prediction API.
  • Data Collector: Gathered and validated historical GDP data for analysis and testing.
  • Project Integrator: Coordinated the integration of all modules and ensured end-to-end functionality.

Why This Project Matters

Our tool aims to help:

  • Policy makers: Simulate potential economic outcomes for strategic planning.
  • Researchers & Students: Understand how growth rates affect long-term economic size.
  • Entrepreneurs: Use forecasts for investment and market strategy insights.

Future Scope

We plan to enhance the model by incorporating real-time data feeds, sector-wise growth projections, and more sophisticated prediction techniques such as machine learning. The current version is just the beginning of a broader economic analysis platform.
